What You’ll Need​

Here’s a checklist of tools and resources to make your learning experience seamless and fun:

1. Computer or Laptop

  • A device with internet access to run tools and tutorials.
  • Any operating system (Windows, macOS, or Linux) works fine!

2. Tools and Software

  • Teachable Machine (Beginner-Friendly Option):
  • A free online platform by Google for training image classifiers.
  • Access it here: Teachable Machine.

Parental Permission and Guidance​

Before starting this tutorial, we recommend that kids check with a parent or guardian for the following:

  1. Internet Access: This tutorial involves using online tools such as Google Earth, Teachable Machine, or Google Colab. Parental permission is advised to ensure appropriate use of these websites.
  2. Account Creation: Certain tools (e.g., Google Earth Engine or Kaggle) may require creating an account. Parents should assist in this process to meet age requirements and protect personal information.
  3. Supervision: While the tutorials are designed for young learners, some steps involve downloading software, using advanced tools, or handling datasets. Parental guidance can make the experience safer and more enjoyable.
